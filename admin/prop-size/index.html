Rules that never change

  • Size from the worst case, never from how sure you feel.
  • Pick the size once and stick to it.
  • Never add size after losses to win it back.
  • Never add size after a big win either.
  • Max $ risk a trade = drawdown limit ÷ (2 × longest losing run).
  • The drawdown limit is fuel in the tank. Every loss burns some. Keep enough to drive through the worst losing run twice.
